# Windows 10/11 x64 迁移验收

1. 整体复制 `visual_servo_system` 目录，不要只复制 `src`。离线 wheel、Python 3.11.9 x64 和
   Spinnaker 安装资源合计约 507 MB；必须随源码复制，但不要复制 `.venv` 或 `.python311`。
   如果目标目录中已有旧 `.venv`，先删除后再安装，不能复用另一台电脑的虚拟环境。
2. 以普通用户运行 `一键离线安装.ps1`。脚本会校验 Python 安装包及全部 wheel 的
   `SHA256SUMS.txt` 和 Python 安装程序的 Authenticode 签名，并只使用 `offline_packages`，
   不会联网。长中文工程路径会用临时 `subst.exe` 盘符和短 TEMP/TMP 自动规避；工程采用
   非 editable 安装，成功或失败后都会解除映射，解除后还会重新验证包导入和启动入口加载。
3. 单独运行 `安装相机驱动.ps1`。脚本会先检查 Spinnaker 目录 SHA256 和完整 EXE 的
   Authenticode 签名，然后要求用户明确输入 `YES` 并确认管理员权限；脚本只运行完整 EXE，
   不会自行拼装执行目录中的 MSI。
4. 统一运行 `启动视觉伺服.ps1`；需要单独诊断环境时使用
   `.\.venv\Scripts\python.exe .\scripts\verify_environment.py`，确认 CTI、依赖和两个标定文件。
5. 按批准顺序完成“相机预览 → 连接机器人只读 → 系统检查 → 干运行”。干运行不发送任何 UR
   运动命令，但本版本仍需 UR5 只读连接来验证状态和时间链，并非不接机器人的纯软件仿真。
6. 再按《实机联调步骤》完成低速实机验收。
7. 验收时保留日志，检查 10 分钟无延迟堆积；断相机、断网或关窗口时若软件无法确认停车，
   界面必须提示使用物理急停，不能显示“已停止”。
