# UR5 实机联调步骤

1. 确认物理急停、安全平面和限位已经现场验收，工作区无人。
2. 运行 `scripts/verify_environment.py`，确认 Python、Spinnaker CTI 和依赖正常。
3. 把真实内参写入 `calibration_files/camera_intrinsics.yaml`，把眼在手上结果写入 `hand_eye_eye_in_hand.yaml`，再把 `calibration_complete` 改为 `true`。
4. UR5 设置为 `192.168.0.10`，活动 TCP 必须六维精确为零。
5. 按界面编号操作：相机预览 → UR5 只读 → 系统检查 → 干运行 → 联调档 → 使能 → 开始跟随。
   “使能”阶段会清空干运行状态，重新等待授权后 RTDE 样本和 10 个真实稳定视觉帧；
   在此过程完成前“开始跟随”不得生效。
6. 首次只使用联调档（50 mm/s）。确认跟随方向、包络和停车正确后，才允许进入试验档。

> 软件停车不能代替 UR 物理急停和现场风险评估。
