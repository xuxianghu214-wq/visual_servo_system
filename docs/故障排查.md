# 故障排查

- **只能预览**：检查两个标定 YAML 是否完整、是否为米制、图像分辨率是否与内参一致。
- **找不到相机**：确认序列号 `16276663`，检查 USB3 线和 `GENICAM_GENTL64_PATH`。
- **提示 `DISPLAYNAME_INCOMPATIBLE_DRIVER` 或“Windows USB 驱动不兼容”**：关闭 SpinView 和本程序，
  运行工程根目录的 `安装相机驱动.ps1`，确认管理员授权，安装完成后重新插拔相机。不要把配置
  分辨率改成 640 来绕过驱动错误。
- **曾提示 `Width 回读值 640 与配置 1280 不符`**：BFS-U3-13Y3C 的原生分辨率是
  1280×1024。实机确认该彩色型号切换到 `Mono8` 会强制 ISP 2x binning，输出变为640×512。
  新版采集模块会先加载厂家 `UserSet Default`，再设置 `BayerRG8`、复位几何节点并设置
  1280×1024。不要把 `camera_settings.yaml` 改回 `Mono8`。
- **延迟不断增大**：程序要求 GenTL `NewestOnly`；节点无法设置时会拒绝启动，不应继续联调。
- **提示 `EKF timestamp gap exceeds max_dt_s` 或视觉线程反复掉线**：先看本次试验目录中的
  `timing.csv` 和 `vision.csv`。新版默认用 `marker_settings.yaml` 的 `detection_scale: 0.5`
  在半分辨率灰度图上搜索标签，再把角点映射回原图并用原始内参完成亚像素精修和 PnP；不要
  缩小相机采集分辨率或修改标定内参。未使能时若单次图像间隔超过 0.25 s，程序会清空过时
  EKF 状态并从当前有效观测重新初始化，不再杀死预览线程；已使能/跟随时仍按故障停车。
  干运行前应确认界面识别率接近或高于 20 Hz、端到端延迟不高于 100 ms。若仍不满足，保留
  新的日志继续排查，不要放宽 EKF、时间戳或安全延迟门限。
- **使能时提示 `target is not stable for the required number of frames`**：保持固定 ID 标签完整、
  清晰且静止，等待连续 10 个有效观测后再点使能。图像间隔、位姿误差或观测质量超限都会把
  稳定计数重新置零；这不是 UR5 逆解故障。
- **TCP 错误**：在 PolyScope 把活动 TCP 设为 `[0,0,0,0,0,0]`，人工确认后重新系统检查、干运行，
  再在实机使能阶段重新建立控制连接和授权。
- **采样时间不可靠**：确认相机 GenTL buffer 提供设备时间且 RTDE 提供 `getTimestamp()`；等待映射
  积累足够连续样本。相机USB门限由 `timestamp_max_uncertainty_s` 单独配置，实机值为20 ms；
  RTDE 使用 `robot_connection.yaml` 中的严格映射门限。重复时间戳不重置映射且不发布，小回退按乱序计数；延迟、真实时基重置或残差过大时禁止实机，但仍可预览/干运行。
- **MPC/RTDE/线程故障**：系统会闭锁在 FAULT。保留 `experiment_logs`，查明原因后点击人工确认，系统不会自动恢复。
